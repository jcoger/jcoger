**Open source**

- [**eagle-refs**](https://github.com/jcoger/eagle-refs). Half of my 3,783 design references had no tags, so they never showed up in a search. This tags every save with a vision model, writes the tags back into Eagle, and lets Claude Code search the whole library.
- [**FontDrop**](https://github.com/jcoger/FontDrop). A Mac app for picking logo type. Drop your logo in and see it set in every font on your machine.
